🤖 The AI Evolution Lab: From Scripts to Autonomous Agents
Welcome to my comprehensive AI learning repository. This project tracks my journey through the modern AI landscape, moving from basic API integrations to building sophisticated, multi-agent autonomous systems.

🏗️ The Full-Stack AI Journey
This repository is organized by "Evolutionary Tiers," representing the different layers of the AI stack. Whether it's running a local model on my machine or orchestrating a team of agents in the cloud, it's all here.

🟢 Tier 1: Foundation & Direct Integration
The "Hello World" of Generative AI. Connecting directly to the brains of the operation.

Direct API Access: Python implementations for OpenAI (GPT-4o) and Anthropic (Claude 3.5) using their native SDKs.

Hugging Face Transformers: Using open-source models for local inference and specialized tasks (Sentiment analysis, NER).

Ollama Integration: Running and prompting local LLMs (Llama 3, Mistral) for privacy and offline development.

🟡 Tier 2: Orchestration & Memory (LangChain)
Moving beyond single prompts into structured workflows and contextual awareness.

LangChain Expressions (LCEL): Building reusable chains for complex logic.

RAG (Retrieval-Augmented Generation): Connecting LLMs to external data using Vector DBs (ChromaDB, Pinecone).

Prompt Engineering: Systematic templates for Few-Shot and Chain-of-Thought prompting.

🔴 Tier 3: Agentic AI & State Management (LangGraph)
The frontier. Building systems that don't just talk, but act and reason.

LangGraph Workflows: Implementing cyclic graphs where models can "loop back" to correct errors or refine thoughts.

Tool Calling: Giving models "hands" to browse the web, execute Python code, or query SQL databases.

Multi-Agent Systems: Orchestrating specialized agents (e.g., a "Researcher" and a "Writer") to collaborate on complex goals.
